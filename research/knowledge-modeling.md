# Knowledge Modeling

[← Profile](../README.md)

**Bilingual terminology → structured concepts → explicit relations → navigable knowledge.**

My undergraduate thesis at Renmin University of China explored a Chinese–Japanese terminology ontology. The work combined Python-based collection, terminology cleaning, RDF relation modeling, and visualization with Protégé and OntoGraf.

| Stage | Technical work |
| --- | --- |
| Collection | Gather terminology and explanations from a public bilingual reference source using Python. |
| Normalization | Clean terms, align bilingual expressions, and organize concepts. |
| Representation | Model classes, properties, and subject–predicate–object relations with RDF. |
| Exploration | Inspect the ontology and visualize concept relations in Protégé and OntoGraf. |

## Connection to AI

An ontology makes domain terms and relationships explicit. In a retrieval-augmented system, that structure can support terminology alignment, relation-aware retrieval, and the organization of context supplied to a language model.

This connection describes how the knowledge-modeling work can transfer to AI. The thesis implemented the ontology prototype; integration with a language model was proposed as future work. It was not an end-to-end RAG implementation.
